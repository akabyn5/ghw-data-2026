# Use GitHub Copilot to Build a Simple Application – Challenge Completed ✅

## 🎉 Challenge Summary

**Challenge Completed: Use GitHub Copilot to Build a Simple Application!** ✅

I put **GitHub Copilot** to the test by having it help me write a fully functional **"Choose Your Own Adventure" CLI game** focused on a thrilling space mission. 

This was an excellent hands-on way to practice **prompt engineering** for specific use cases and experience firsthand how much an AI assistant can speed up standard application development — from initial structure to polished features.

### Project Description
A text-based **Choose Your Own Adventure** game set in a space exploration mission. Players make critical decisions that determine the outcome of their journey through space, facing challenges such as asteroid fields, alien encounters, system failures, and resource management.

---

## 🚀 What Was Built

### Game Features
- Interactive command-line interface
- Multiple branching story paths
- Multiple endings (success, failure, and alternate outcomes)
- Inventory / resource management system
- Engaging space-themed narrative
- Clean, well-commented Python code

### Skills Practiced
- Effective **prompt engineering** with GitHub Copilot
- Iterative development with AI assistance
- Structuring a CLI application
- Implementing decision trees and game logic
- Code documentation and user experience refinement

This project demonstrated how Copilot can dramatically accelerate development while still requiring human oversight for architecture, creativity, and quality control.
