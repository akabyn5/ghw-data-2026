## Overview

For this challenge, I used **GitHub Copilot** throughout the development of my project after claiming my **GitHub Student Developer Pack**. ## What I Used Copilot For

- Generating Python functions and classes.
- Creating the command-line interface (CLI).
- Improving game logic and control flow.
- Refactoring repetitive code.
- Debugging small issues during development.
- Writing comments and documentation.

Using Copilot significantly reduced development time and allowed me to focus on game mechanics rather than boilerplate code.
