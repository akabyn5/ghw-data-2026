Our team completed the Tiger Cloud hypertable challenge for MLH Global Hack Week: Data. We created a new TimescaleDB service named ghw-data-hypertable and built our first hypertable called conditions. The table stores time-series sensor data with columns for time, location, device, temperature, and humidity. We configured it with device-based segmentation and time-descending order, inserted sample records, and verified the hypertable using TimescaleDB system views.
